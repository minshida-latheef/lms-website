# 🎓 Learning Management System (LMS)

A simple and responsive Learning Management System website designed to provide an easy platform for students to explore courses and manage their learning activities.

## ✨ Features

- 🏠 Home page
- 📚 Course listing
- 👨‍🎓 Student dashboard
- 📖 Course details
- 🎨 Clean and user-friendly design
- 📱 Responsive layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
